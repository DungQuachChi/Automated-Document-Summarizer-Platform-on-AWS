This section will list and introduce the blogs you have posted to [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj). For example:

###  [Blog 1 - Exploring the CloudWatch Logs Enhanced Automatic Dashboard – A Helper for Monitoring Volume and Optimizing Log Costs on AWS](3.1-Blog1/)
This blog introduces the newly launched CloudWatch Logs Enhanced Automatic Dashboard, a free, out-of-the-box dashboard that visualizes log ingestion, API usage, anomaly detection, and data protection across an account. It's a useful reference for spotting cost drivers and catching logging issues early without building a custom dashboard.

###  [Blog 2 - Exploring Multi-Region Event-Driven Failover Architecture with Amazon EventBridge and Route 53 – A Multi-Region Failover Architecture for Event-Driven Applications](3.2-Blog2/)
This blog explores an Active-Passive Multi-Region Failover architecture that combines Route 53, EventBridge, API Gateway, and DynamoDB Global Tables to keep event-driven applications running automatically even if an entire AWS Region goes down. It highlights how the design achieves zero-manual-intervention failover while keeping data consistent across Regions.

###  [Blog 3 - Exploring build Secure B2C Applications with Fine-Grained Access Control Using Amazon Cognito and Amazon Verified Permissions](3.3-Blog3/)
This blog explores how combining Amazon Cognito with Amazon Verified Permissions offloads fine-grained authorization decisions to a dedicated policy engine using the Cedar language, instead of hardcoding permission logic into backend code. It's especially relevant for B2C or multi-tenant SaaS applications that need flexible, auditable, attribute-based access control.
