Phần này ghi lại tiến độ và lộ trình phát triển của dự án tốt nghiệp **Nền Tảng Tóm Tắt Tài Liệu Serverless Tự Động Trên AWS**. Dự án được hoàn thành trong khoảng thời gian 15 tuần, bao gồm thiết kế kiến trúc, phát triển backend serverless, tích hợp AI với Amazon Bedrock, bảo mật, tự động hóa hạ tầng, và tài liệu kỹ thuật.
Dưới đây là bảng phân chia công việc theo từng tuần trong suốt chương trình:

**Tuần 1:** [Làm quen với AWS và các dịch vụ AWS cơ bản](1.1-week1/)

**Tuần 2:** [Thiết kế kiến trúc, thiết lập môi trường, và khởi tạo repository](1.2-week2/)

**Tuần 3:** [Thiết lập xác thực người dùng với Amazon Cognito](1.3-week3/)

**Tuần 4:** [Xây dựng logic tóm tắt backend với AWS Lambda và Amazon Bedrock](1.4-week4/)

**Tuần 5:** [Chỉnh sửa template workshop Hugo và soạn thảo báo cáo ban đầu](1.5-week5/)

**Tuần 6:** [Thiết kế và triển khai lưu trữ lịch sử với Amazon DynamoDB](1.6-week6/)

**Tuần 7:** [Tạo REST API với Amazon API Gateway và Cognito Authorizers](1.7-week7/)

**Tuần 8:** [Xác thực request API, xử lý lỗi, và định dạng payload](1.8-week8/)

**Tuần 9:** [Cấu hình caching và quy tắc giới hạn tốc độ (rate-limiting) cho API Gateway](1.9-week9/)

**Tuần 10:** [Thiết lập luồng xử lý tài liệu bất đồng bộ với SQS](1.10-week10/)

**Tuần 11:** [Tích hợp backend, tối ưu hóa prompt Bedrock, và xử lý lỗi](1.11-week11/)

**Tuần 12:** [Quản lý nhánh Git cục bộ, hợp nhất quy trình làm việc, và thiết lập xem trước Hugo](1.12-week12/)

**Tuần 13:** [Xử lý tài liệu (PDF/DOCX), theo dõi AWS X-Ray, và tích hợp Web UI](1.13-week13/)

**Tuần 14:** [Infrastructure as Code (IaC) với Terraform, CI/CD với GitHub Actions, và kiểm thử tải](1.14-week14/)

**Tuần 15:** [Chỉnh sửa template workshop, hoàn thiện báo cáo kỹ thuật, và rà soát tài liệu cuối cùng](1.15-week15/)
