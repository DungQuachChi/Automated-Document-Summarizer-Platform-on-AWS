This section documents the progress and development timeline for the **Automated Document Summarizer Platform on AWS** capstone project. The project was completed over a 15-week period, covering architectural design, serverless backend development, AI integration with Amazon Bedrock, security, infrastructure automation, and technical documentation.

Below is the weekly breakdown of the tasks performed throughout the program:

**Week 1:** [Getting familiar with AWS and basic AWS services](1.1-week1/)

**Week 2:** [Architecture design, environment setup, and repository initialization](1.2-week2/)

**Week 3:** [User authentication setup with Amazon Cognito](1.3-week3/)

**Week 4:** [Building backend summarization logic with AWS Lambda and Amazon Bedrock](1.4-week4/)

**Week 5:** [Hugo workshop template editing and initial report drafting](1.5-week5/)

**Week 6:** [Designing and deploying history storage with Amazon DynamoDB](1.6-week6/)

**Week 7:** [Creating REST APIs with Amazon API Gateway and Cognito Authorizers](1.7-week7/)

**Week 8:** [API request validation, error handling, and payload formatting](1.8-week8/)

**Week 9:** [Configuring API Gateway caching and rate-limiting rules](1.9-week9/)

**Week 10:** [Setting up asynchronous document processing workflows with SQS](1.10-week10/)

**Week 11:** [Backend integration, Bedrock prompt optimization, and error handling](1.11-week11/)

**Week 12:** [Local Git branch management, workflow consolidation, and Hugo preview setup](1.12-week12/)

**Week 13:** [Document processing (PDF/DOCX), AWS X-Ray tracing, and Web UI integration](1.13-week13/)

**Week 14:** [Infrastructure as Code (IaC) with Terraform, CI/CD with GitHub Actions, and load testing](1.14-week14/)

**Week 15:** [Workshop template editing, technical report completion, and final documentation review](1.15-week15/)
